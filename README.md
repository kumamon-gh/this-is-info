Spotifyが提供する特定のアーティストの代表曲をまとめた公式プレイリストシリーズです。
アルゴリズムが最新のトレンドやリスナーの反応を反映し、選曲を更新！
そんなベスト盤のようなプレイリストをまとめました。

ボタンの使い方

ボタン（緑）：キーボード（キーパッド）
ボタン（黒）：トップに戻る

ボタン（♡）：お気に入り一覧（リストで「♡」を押すとこちらに保存される）
ボタン（↓/↑）：昇順（降順）※ 切り替え
ボタン（🔀）：ランダム
ボタン（▶️AUTO/■ STOP）：自動スクロール（停止）※ 切り替え

※ 自動スクロールはリスト最後尾に到達するとトップに戻り停止します
※（黒）ボタンをダブルタップしても「お気に入り一覧」を開け、もう一度ダブルタップすると閉じます
※ お気に入りに保存したアーティストはもう一度「♡」を押すことで解除できます
※ 閲覧履歴の保存は30日後に自動で削除されます
